# The Last One

림월드 1.7용 모드입니다. 별도의 인간형 종족인 **단독종**과 해당 종족의 생존자 한 명으로 시작하는 시나리오를 추가합니다.

## 주요 동작

- `마지막 하나` 시나리오에서는 단독종 폰 하나만 생성되고, 시작 폰 선택에서도 해당 폰 하나만 필수입니다.
- 종족 전용 폰 종류를 다른 팩션이나 월드 생성 정의에 등록하지 않아 자연 발생하지 않습니다.
- 외형은 기본 인간형 그래픽을 사용합니다. 별도 그래픽이나 종족 특성은 포함하지 않습니다.

## 설치

이 폴더를 `RimWorld/Mods/TheLastOne`에 복사하고 게임의 모드 메뉴에서 활성화합니다. 새 게임 시나리오에서 `마지막 하나`를 선택하세요.
